# ريح بالك (ReehBalak) 0.2.0

## التشغيل في Android Studio
1. File ‹ Open ‹ مجلد ReehBalak، وانتظر Gradle Sync (يحتاج إنترنت أول مرة).
2. Run ▶ على هاتف Android 10+ (أو Build ‹ Build APK).
3. اختبارات الوحدة: Android Studio ‹ كليك يمين على `app/src/test` ‹ Run Tests.

## سير العمل
اتصال ← قراءة الإعدادات ← إنشاء قالب (اختيار الأقسام) ← جهاز جديد ← اتصال ←
برمجة تلقائية ← معاينة ← تطبيق ← تقرير.

## الأمان
- بصمة SSH تُؤكَّد يدويًا وتُحظر عند تغيّرها.
- كلمة المرور في الذاكرة فقط.
- يُستبعد دائمًا: MAC، مفاتيح خاصة/عامة، أقسام device وswitch وWireGuard، خيارات path/phy.
- كلمات مرور Wi-Fi وPPPoE تُستبعد ما لم تفعّل «تضمين كلمات المرور».
- قبل كل تطبيق: نسخة احتياطية محلية + نسخة على الراوتر + تراجع تلقائي بعد 150 ثانية.
- التحقق بعد التطبيق؛ عند الفشل يتراجع الجهاز.
- لا إعادة ضبط مصنع ولا تعطيل للجدار الناري تلقائيًا.

## القيود المعروفة
- التطبيق «دمج» فقط: يضيف ويعدّل ولا يحذف أقسامًا زائدة على الجهاز.
- لا قراءة/تثبيت للحزم (opkg) بعد.
- لا دعم لأجهزة غير OpenWrt (البنية جاهزة للإضافة).
- الاستعادة تتم لنفس اللوحة فقط.
- لم يُجرَّب على راوتر حقيقي بعد.
